## پیش‌نیازها

- JDK 17 یا جدیدتر (پروژه با `--release 17` کامپایل می‌شود)
- نیازی به نصب Gradle نیست؛ از Gradle Wrapper همراه مخزن استفاده کنید (`./gradlew`، در ویندوز `gradlew.bat`)

## دستورات

```bash
./gradlew build      # کامپایل + تست + Checkstyle + PMD (طبق قوانین لینتر سند پروژه)
./gradlew test       # فقط اجرای تست‌ها
./gradlew check      # فقط تست + لینترها
./gradlew run        # اجرای بازی (ورودی/خروجی ترمینال)
./gradlew installDist   # ساخت توزیع اجرایی در build/install/plants-vs-zombies/
```

## گیاهان

هر ۶۹ گیاهِ شیت پروژه پیاده شده‌اند (به‌علاوه‌ی چند گیاه اضافه‌ی خودمان). یک گیاه
«داده» است نه «کد»: هر گیاه یک سطر در `src/main/resources/data/plants.csv` با نام،
دسته، هزینه، ریچارج، جان، دمیج، بازه‌ی حمله و تگ‌هاست. دسته رفتار پایه را تعیین
می‌کند (`PlantCombat`) و تگ‌ها رفتار اختصاصی را (`PlantAbilities`)، پس افزودن گیاه
جدید معمولاً فقط یک سطر CSV و یک تصویر است.

واژگان تگ‌ها:

| تگ | معنی |
| --- | --- |
| `day` / `night` | زمان مناسب گیاه |
| `pea`, `ice`, `fire`, `poison`, `shroom`, `water`, `magic`, `sun`, `explosive`, `trap`, `aoe` | خانواده و خاصیت طبق شیت |
| `sun:N` | مقدار خورشیدی که هر دوره تولید می‌کند |
| `three-lane`, `split`, `star`, `diagonal` | شلیک به لاین‌های دیگر یا به عقب |
| `stack` | روی هم کاشته می‌شود (Pea Pod، Lily Pad) و `shield` (کدو) دور گیاه می‌پیچد |
| `wramp-up` | با گذر زمان قوی‌تر می‌شود (Sun-shroom، Kiwibeast) |
| `lifespan` | بعد از ۶۰ ثانیه پژمرده می‌شود (Puff/Sea-shroom) |
| `butter`, `bounce`, `pierce`, `insta-kill`, `reflect`, `sun-on-hit`, `magnet`, `hypno` | اثر هنگام برخورد یا خورده‌شدن |
| `moveZombies` + `push` / `pull` | سیر و سیب‌زمینی شیرین که زامبی را بین لاین‌ها جابه‌جا می‌کنند |
| `instant` | یک‌بار عمل می‌کند و ناپدید می‌شود |
| `lane`, `whole-map`, `crater`, `melt`, `grave-buster` | برد اثر گیاهان انفجاری و کاربردی |
| `mint` + `family:<دسته>` | نعناها؛ به کل خانواده‌ی خود غذای گیاه می‌دهند و ریچارجشان را صفر می‌کنند |
| `imitate` | Imitater؛ آخرین گیاهی که کاشته‌اید را کپی می‌کند |

گیاهان جدید از دو راه باز می‌شوند: کوئست‌های داستانی هر فصل (هر کدام چند گیاه
مربوط به همان فصل) و خرید با سکه در منوی کلکسیون.

سایر مسیرها:

```
src/main/resources/            دیتای بازی، تصاویر (assets/)، صدا (audio/) و استایل
tools/                         خط لوله‌ی استخراج تصاویر از اطلس‌های بازی اصلی
src/test/java/ir/sharif/pvz/   تست‌ها
docs/                          دیاگرام‌های UML و مستندات طراحی
checkstyle.xml / pmd-ruleset.xml   قوانین لینتر مطابق سند پروژه
data/                          دادهٔ ذخیره‌شده در زمان اجرا (users.json، سشن) — در گیت نیست
UML.png                        دیاگرام کلاس اولیه (فاز صفر)
```
